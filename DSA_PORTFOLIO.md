# DSA Interview Portfolio (Python)

A curated collection of **55+ classic data-structure and algorithm implementations** organized in `portfolio_solutions.py`. Intended as a study and interview-preparation portfolio—not a claim that every problem was independently solved under timed conditions.

## Topics
Arrays & hashing · Two pointers · Sliding windows · Stacks · Binary search · Linked lists · Trees · Heaps · Backtracking · Tries · Graphs · Dynamic programming · Greedy · Intervals · Bit manipulation · Matrix operations · LRU cache.

## Quick start
Requires Python 3.10+; standard library only.

```bash
python -m py_compile portfolio_solutions.py
```

Import functions directly:
```python
from portfolio_solutions import three_sum, coin_change, can_finish
```

## Interview preparation standard
For every solution, be ready to explain:
1. The brute-force baseline and why it is inefficient.
2. The key invariant / state transition.
3. Time and auxiliary-space complexity.
4. Edge cases and trade-offs.

Please review, test, and personalize solutions before presenting them as your own work.
